05 · DO & DON'T
写法对照

写法对照

这个 skill 跟"自由发挥写 demo"的根本差别 —— 体现在每一处写法的选择上。

✓ GOOD
  • 用 mod-04-search-section.html 拼搜索框
  • 圆角 16px(规范固定)
  • color: #00B277 = 品牌色
  • 17 区块按 mod 顺序拼,不漏
× BAD
  • 自己重写搜索框样式
  • 圆角随手改成 8px 试试效果
  • 把品牌绿改成更鲜艳的绿"看看"
  • 挑几个 mod 拼,跳过商用授权区块
06 · HOW
执行流程

执行流程

4 步从触发到交付。每一步都对应一份真实文档或模块。

01
读 references/main-site-tokens.md,把 CSS 变量记下来 —— 后面用 var() 引用,不要硬编码。
02
确认要做的页面是首页 / 搜索结果 / 素材详情 / 会员购买 哪一个,场景不同模块不同。
03
从 demo-source/main-site/modules/ 抓对应模块,17 个 mod 文件按场景挑,不修改 class 名。
04
拼成完整页面,前端拿到后可直接复用 mod 文件,不需要基于 demo 重写。
