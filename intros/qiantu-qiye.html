02 · WHY
解决什么

企业站两套主题易混淆
深色 / 浅色严格分离

企业站有两套主题 —— 深色工作台用蓝色,浅色营销页用红色 —— 这两套绝不可混用。凭印象做 demo,80% 概率第一稿就主题混了。这个 skill 把分离规则写死。

BEFORE
凭文档猜的 demo
  • 首页给个浅色主题看着不"沉"
  • 定价页放个蓝色 CTA 显得"科技"
  • 充值弹窗给个纯白底"干净点"
  • 主题混乱,B 端品牌识别度全无
→
AFTER
用源文件组装
  • 工作台(首页)= 深色 + 纯蓝
  • 定价 / 充值 = 浅色 + 红色
  • 两套规则不可逾越,demo 就稳了
  • 前端拿到代码风格干净统一

05 · DO & DON'T
写法对照

写法对照

这个 skill 跟"自由发挥写 demo"的根本差别 —— 体现在每一处写法的选择上。

✓ GOOD
  • 首页(工作台)用深色 + 纯蓝 #1980FF
  • 定价页 / 充值弹窗用浅色 + 红 #FA5555
  • 充值弹窗用渐变背景(从粉到浅)
  • 主色 token 写死,不靠手感判断
× BAD
  • 首页改成浅色"显得清爽"
  • 定价页 CTA 用蓝色"显得专业"
  • 充值弹窗给个纯白底"干净"
  • 主题混用,B 端识别度全丢
06 · HOW
执行流程

执行流程

4 步从需求到代码。第 1 步决定主题方向,错了后面全错。

01
确认页面类型 —— 工作台 / 定价页 / 充值弹窗?这决定用哪套主题,选错就全错。
02
工作台 → 用深色主题 + 纯蓝主色。读 enterprise-site-tokens.md 拿 --qte-* 变量。
03
定价 / 充值 → 用浅色主题 + 红色主色。读对应 tokens 拿 --vip-red、--vip-bg-grad 变量。
04
从 assets/enterprise-site/ 抓对应模块的 HTML / CSS,直接内联,不做改写。
