不够看：主体不突出、版式散

03 · LOCKED
不可绕的硬约束
03 / 08

三条铁律，不允许 AI 自由发挥

HARD RULES
⊘ LOCKED

套图一起判

is_series=true 的作品必须看完整套（主图 + 所有子图）才下结论。要么全过要么全驳，不允许某张过某张驳。writeback 时自动展开为整套回写。

trigger is_series === true
output 只输出主图条目
writeback 主图+子图一起回写
⊘ LOCKED

字体严标

标准字体不存在原创字形。凡键盘打 + 字库渲染的字（包括"手写风"字库如汉仪粗黑、字魂手书）都必须标到 marked_fonts。看不准 → 按"必须标"处理。

必标 黑 / 宋 / 楷 / 圆 / 隶
必标 思源 / 字魂 / 方正
必标 "手写风" 字库字体
可不标 真手绘字
⊘ LOCKED

驳回必须一次列全

驳回时必须把发现的所有问题一次写完，不许只挑一个写。设计师按建议改完再驳第二个 = 反复返工 = 审核失职。理由 ID 多问题可到 3-4 个。

flow 扫全 → 排严重度
flow 一次写全 → 给具体建议
limit reject_ids 3-4

⊘ 边界

  • 不替代人工复审（必须经面板确认才回写）
  • 不做视频/3D/音频专项审核（一期只覆盖 2D + 视频帧）
  • 不在 token 失效时降级到样例继续跑
  • 不绕过任一硬性约束（即使用户要求）
  • 不为子图单独输出条目（套图只输出主图）
  • 不允许 AI 拟合「明显垃圾稿」的主观判定
